Here, I provide a collection of software and resource for free use.

Currently, the collection includes

- [The R package *LSAfun*](/software-resources/r_packages/)
- [A collection of downloadable semantic spaces](/software-resources/semantic_spaces/)
- [A web application and a downloadable version of the ViSpa (Vision spaces) system](/software-resources/vispa/)
- [Video tutorials for software applications](/software-resources/video_tutorials/)
- [Resources for Centroid Analysis](/software-resources/centroid-analysis/), a technique to estimate concept representations from open-form responses
- [*PsychoEmbeddings*, a Python package to extract contextualized word vectors (Attanasio & Bianchi)](/software-resources/psychoembeddings/)
- [The Flickr frequency norms](/software-resources/the-flickr-frequency-norms/)
- [A database of semantic transparency measures for English compounds](/software-resources/english_st/)
- [A database of semantic transparency measures for German compounds](/software-resources/german_st/)
- [A database of vision-based semantic transparency measures for English compounds](/software-resources/vision-based-semantic-transparency-measures-for-english-compounds/)
- [A database of taboo language in 13 languages, collected in 17 countries](/software-resources/taboo-language-database/)
