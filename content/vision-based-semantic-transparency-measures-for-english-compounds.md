### Existing compounds

This dataset contains semantic transparency measures for a set of 736 existing English compound words. The data is presented in the following article:

[Günther, F., Petilli, M. A., & Marelli, M. (2020). Semantic transparency is not invisibility: A computational model of perceptually-grounded conceptual combination in word processing. *Journal of Memory and Language*, *112*, 104104.](https://doi.org/10.1016/j.jml.2020.104104)

[**Link to the dataset**](https://osf.io/kmrv7/)

Unlike the semantic transparency measures provided [here](/software-resources/english_st/), these semantic transparency measures are derived from a deep convolutional computer vision network (for more details, see [here](/software-resources/vispa/)).
